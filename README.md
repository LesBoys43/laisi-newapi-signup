NewAPI中转站注册码框架

# 摘要

本框架利用New API管理员API，创建了一个独立站点用于注册，在此处注册强制使用注册码，管理员可利用本框架高效管理中转站注册。

# 新用户入门

## 先决条件

- PHP: 8.3以上
- PgSQL: 9.4以上
- Node: 20以上
- Web服务器: 任何

## 安装

### 依赖

使用`composer install`和`npm install`命令安装依赖项

### 初始化数据库

在PgSQL上创建一个数据库，并执行`setup.sql`安装所有表。

### 配置

复制`Settings.php.sample`到`Settings.php`，根据其中的引导修改各项参数。

### 构建前端

使用`node build.mjs`构建前端。

# 使用手册

## 管理员

点击导航栏的*管理员*按钮，输入密码登录后，将看到仪表板。

## 仪表板

### 主面板

主面板展示所有注册码，包含以下字段：

**ID**:
注册码在数据库中的唯一ID。

**注册码**:
注册码字符串。

**使用情况**:
注册码的使用情况芯片，将鼠标悬浮在芯片可看到具体信息

**动作**:
几个操作注册码的按钮

### 上面板

上面板包含部分复杂操作：

**创建注册码**:
点击此按钮后，在弹出的弹出框中，可以选择注册码的配额，支持从预设配额中选择或者输入自定义配额。

## 用户

点击首页的注册大按钮后，在弹窗内输入管理员给你的注册码，也可输入自定义昵称，点击注册后将看到New API上的用户名和密码。

### 常见错误

**Code does not exists.**
你输入的注册码不存在，请检查是否复制错误，或联系管理员。

**Code ran out of quota.**
注册码配额用尽，联系管理员获取新的注册码。
